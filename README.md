# Christ Attendance System

A simple, premium, white-themed Attendance Management System built for **Christ University** using HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features
- **Dashboard Overview**: Teacher/Professor greeting, overall stats (student count, average class attendance, and today's status).
- **Attendance Sheet**: Take attendance for classes (**MCA A**, **MCA B**, and **MSC AI ML**). Toggle between `P` (Present), `A` (Absent), `L` (Late Arrival), `M` (Medical Leave), and `I` (Informed Leave).
- **Admin POV Reports**:
  - **Class Report**: Summary performance table of all students, class average circular progress, and class-wide aggregated leave/presence metrics.
  - **Individual Report**: Detailed day-by-day attendance history, individual percentage ring, and leaf metrics.
- **Monogram Avatars**: Lightweight, fast, and visually premium text-initial monograms instead of external images.
- **Local Persistence**: Saves all records to `localStorage` for offline use.

## 🛠️ Technology Stack
- **Structure**: HTML5
- **Styling**: Custom CSS3 (Vanilla)
- **Logic**: ES6 JavaScript
- **Icons**: FontAwesome v6
